Dokumentasi API

Selamat datang di dokumentasi resmi REST API. API ini dirancang menggunakan arsitektur RESTful standar dengan format pertukaran data JSON.

Base URL

https://api.domain-anda.my.id/v1

Autentikasi

Setiap permintaan ke API wajib menyertakan API Key pada bagian Header HTTP menggunakan skema Bearer Token.

HTTP Header 
Authorization: Bearer YOUR_SECRET_API_KEY
Accept: application/json
GET /users/{id}

Ambil Informasi Pengguna

Mengambil detail profil pengguna berdasarkan ID unik yang terdaftar di sistem.

Parameter Tipe Keterangan
id * string ID unik pengguna (Path parameter)
Contoh Request (cURL) 
curl -X GET "https://api.domain-anda.my.id/v1/users/USR-1029" \
  -H "Authorization: Bearer YOUR_SECRET_API_KEY"
200 OK — Response 
{
  "success": true,
  "data": {
    "id": "USR-1029",
    "username": "dapjisync_dev",
    "status": "active",
    "created_at": "2026-11-23T10:00:00Z"
  }
}
