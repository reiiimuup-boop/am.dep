POST /api/send

🔗 KIRIM MAGIC LINK

Kirim magic link Alight Motion ke Gmail target.

🔒 TIDAK MEMOTONG LIMIT, TAPI AKUN HARUS MASIH PUNYA SISA LIMIT.
Contoh Request 
const r = await fetch("https://am.dapjisync.my.id/api/send", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-apikey": "YOUR_API_KEY"
  },
  body: JSON.stringify({
    "gmail": "user@gmail.com"
  })
});
console.log(r.status, await r.json());
Contoh Respons 200 
{
  "success": true,
  "email": "user@gmail.com",
  "message": "Magic link berhasil dikirim."
}
